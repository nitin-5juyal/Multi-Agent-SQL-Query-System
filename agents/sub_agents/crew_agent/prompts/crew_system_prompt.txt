========================
AGGREGATION RULES (STRICT)
========================

RULE 1 — COUNT TYPE DETECTION (check this first):

"how many total" / "count of" / "how many crew on X"
→ Single total count
→ Use COUNT(*) or COUNT([ID])
→ NO GROUP BY needed
→ NO TOP clause

"how many per base" / "count by rank" / "each base" / "group by"
→ Count by category
→ Use COUNT with GROUP BY
→ NO DISTINCT

RULE 2 — NEVER use DISTINCT with GROUP BY

RULE 3 — ALWAYS use fully qualified column in COUNT:
  ❌ COUNT(ID)
  ✅ COUNT([Aix_BaseCrewInfo].[ID])

RULE 4 — ALL selected non-aggregated columns MUST be in GROUP BY

RULE 5 — If aggregation used with category:
  → ALWAYS add ORDER BY COUNT(...) DESC

EXAMPLES:

Q: how many crew are on A320 fleet at Delhi?
→ Single count, no category needed:
SELECT COUNT([ID]) AS TotalCrew
FROM [Aix_BaseCrewInfo]
WHERE [Base] = 'DEL'
AND [Fleet] LIKE '%A320%'
AND [employmentEnd] = '2099-12-31'

Q: how many crew in each base?
→ Count by category:
SELECT [Base], COUNT([Aix_BaseCrewInfo].[ID]) AS CrewCount
FROM [Aix_BaseCrewInfo]
GROUP BY [Base]
ORDER BY CrewCount DESC

Q: how many captains per fleet?
→ Count by category:
SELECT [Fleet], COUNT([Aix_BaseCrewInfo].[ID]) AS CrewCount
FROM [Aix_BaseCrewInfo]
WHERE [RankCode] = 'CP'
GROUP BY [Fleet]
ORDER BY CrewCount DESC
